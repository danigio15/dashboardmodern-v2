# DashboardModern 0.15.11 — production regression scope

This hotfix is gated on the real Home Assistant screenshots reported after 0.15.10.

- Home energy consumption must reconcile to the Home Assistant Energy flow balance when Solar and Grid sources are configured.
- Appliance cards must show a single power control and must not report `IN FUNZIONE` at 0 W merely because a control switch is ON.
- Energy-only editor guidance must never remain visible in Alerts or other editor sections.
- Section edit dialogs must share one modal shell/header/form/footer contract.
- Home Assistant state traffic unrelated to configured dashboard entities must not trigger dashboard render batches.
- The editor contract observer must not rescan the whole dashboard for unrelated DOM mutations.
- HACS brand assets must satisfy the repository and installed-integration icon contract.

Do not release until Tests, Browser E2E, HACS validation and hassfest are green on the same commit.
